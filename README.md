# Keith

Developer who likes building things and figuring out how systems work.

My projects tend to wander through game servers, mapping tools, networking, desktop utilities, and the occasional questionable experiment.

Currently working on **Otter Game**, an early multiplayer game project with a [Java/Quarkus server](https://github.com/Astarisk/otter-game) and a [TypeScript/Three.js client](https://github.com/Astarisk/otter-client). Both are still taking shape.

### Things I work with

**Languages:** Java · Python · TypeScript / JavaScript · SQL · Clojure  
**Tools & frameworks:** Quarkus · Django · React · Three.js · Leaflet · Docker · Maven · Bun

### A few projects

- **[CiderMap](https://github.com/Astarisk/cidermap)** — a Python/Django automapping project for Haven & Hearth, with uploaded map tiles, markers, and a Leaflet/PixiJS map.
- **[OtterShare](https://github.com/Astarisk/OtterShare)** — an older Windows screenshot-sharing experiment in Python, exploring native input hooks, image capture, and Imgur uploads.
- **[RawrfenWeb](https://github.com/Astarisk/RawrfenWeb)** — an older experiment connecting a browser chat interface to Haven & Hearth through a Python WebSocket bridge.

Some of these are unfinished or from earlier adventures in learning. They're part of the collection.
